Implement the baseline file's event schema and host reducer. Minimum continuous
channels: simulation work, DL translation/submit, GE/vblank waits, distinct
fronts, audio playable frames/underruns, packed read/lock times, scene/object
ready/first-use, memory peaks. Add switchable scopes for AI/collision/animation,
constructor, asset transforms, texture upload and ME command construction.
Capture rare outliers cheaply. Keep fixed-size rings bounded with overflow
counts, thread-local writes and off-path flushing. Guard startup, wake/timer
wrap and partial captures. Annotate input edges and hash selected stable fields
after ticks. Host fixture: synthetic overlapping intervals, repeated framebuffer,
missing event, wrap and stale generation; manually known reducer results.

Run python3 tools/tests/test_psp_frame_pacing.py and
python3 tools/tests/test_psp_wake_trace.py. Capture three paired cold/warm

frame tails and RAM, give measured observer cost. Pass when counts reconcile
per tick/render/scanout, intended windows have zero trace loss, measurements
are reproducible and residual measurement bias is quantified. If full capture
perturbs the deadline, split traces under identical inputs. First product is
a real before baseline; no speedup is expected from instrumentation.
