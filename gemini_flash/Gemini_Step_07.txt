1. MISSION & EXACT SCOPE
----------------------------------------------------------------------
Prerequisite Gate: Step 06 MUST be `PASS`.

Your objective in Step 07:
1. Create `crates/pmm-audio` (`#![no_std]` + `alloc`), implementing the 32 kHz
   Majora's Mask audio synthesis, sequence/SFX playback, and PSP hardware audio
   output subsystem defined in `docs/architecture/PSP_RUST_ARCHITECTURE.txt`:
   - N64 VADPCM / PCM16 Sample Decoder & Envelope Mixer (`envmixer`):
     * Decodes 9-byte VADPCM frames (1-byte header with scale + predictor index,
       8 bytes of 4-bit nibbles -> 16 PCM16 samples using 2nd-order IIR predictor
       codebooks from `OSFT` SoundFont resources) and raw PCM16 samples.
     * Mixes up to 16 active voice channels with pitch resampling (`f32` / 16.16
       fixed-point step), ADSR envelope ramps, stereo panning, and reverb wet/dry
       ring buffer into stereo 16-bit PCM frames at **32,000 Hz** (`1,600` stereo
       samples per 20 FPS tick, emitted in `512` or `1,024`-sample blocks).
   - Sequence & SFX Trigger Engine (`AudioSeq` / `AudioSfx`):
     * Supports triggering UI/gameplay SFX (cursor move, confirm, cancel, clock bell,
       dawn rooster, sword slash) and looping background sequences (Title Theme,
       File Select Fairy Fountain, Clock Town Day 1/2/3 tempo scaling with day!).
   - PSP Audio Thread & Hardware Output (`src/platform/audio_psp.rs`):
     * Allocates sample/ring buffers inside Pool 4 (`AudioPool` 8 MiB).
     * Reserves a PSP audio channel via `sceAudioSRCChReserve(1024, 32000, 2)`
       (hardware 32 kHz -> 44.1 kHz SRC) with automatic fallback to standard
       `sceAudioChReserve(PSP_AUDIO_NEXT_CHANNEL, 1024, AudioFormat::Stereo)` +
       linear 32 kHz -> 44.1 kHz resampler if SRC channel is busy.
     * Runs a dedicated kernel audio worker thread (`sceKernelCreateThread`,
       priority `0x12`) that pulls command buffers from `pmm-audio` and calls
       `sceAudioSRCOutputBlocking` / `sceAudioOutputPannedBlocking`, counting
       completed audio buffers in an `AtomicU32`.
2. Implement Coordinated Power Suspend / Resume & HOME Exit (`src/platform/power.rs`):
   - Registers `sceKernelRegisterPowerCallback` and `sceKernelRegisterExitCallback`.
   - Implements `PowerCoordinator::enter_suspend()` and `resume_from_suspend()`:
     * Pauses audio worker thread (`AUDIO_PAUSED = true`), waits for current audio
       block & `sceGuSync`, closes `pmm-assets` `PakReader` file descriptor, and
       records suspend state.
     * On resume, re-opens `data/pmm_2s2h.pak`, restores `sceGu` context, resets
       RTC frame-pacing delta so the 3-Day Clock does not jump forward by sleep
       duration, and unpauses the audio worker thread.
3. Run host unit tests on VADPCM decoding, ADSR envelope mixing, and 32->44.1 kHz
   resampling, AND run a 120-tick audio + simulated suspend/resume test in PPSSPP
   (`PSPModel = 1`), writing `step07_audio_power.log`.
