       lists are compiled once on first use into immutable native PSP vertex buffers +
       cached GE sub-lists (`sceGuStart(GuContextType::Call, ...)` -> `sceGuCallList`), so

       pre-swizzled textures (`sceGuTexMode(psm, 0, 0, 1)`) and track `ActiveGpuState`

       `sceGuTexImage` / `sceGuBlendFunc` emissions.

     * Matrix stack (`G_MTX`, `G_POPMTX`): converts N64 16.16 fixed-point `Mtx` (64 B)
       to `ScePspFMatrix4` (`f32` 4x4) and multiplies MVP matrices (with software near-plane
       clipping for triangles spanning `z < near` so PSP hardware guard-band never overflows).
     * Vertex & Triangle emission (`G_VTX = 0x01`, `G_TRI1 = 0x05`, `G_TRI2 = 0x06`,
