G) `src/main.rs` Probe Requirements:
   - `#![no_std]`, `#![no_main]`, `extern crate alloc;`
   - `psp::module!("PocketMajoraProbe", 1, 0);`
   - Setup exit callback via `psp::callback::setup_exit_callback().unwrap();`
   - Query `unsafe { psp::sys::sceKernelTotalFreeMemSize() }` and
     `unsafe { psp::sys::sceKernelMaxFreeMemSize() }` BEFORE any heap/partition
     allocation.
   - Allocate a `Vec<u8>` of 64 KiB on the Rust heap (`alloc::vec![0xAAu8; 65536]`)
     and query `psp::alloc_impl` / free memory.
   - Attempt to allocate a `16 * 1024 * 1024` byte (16 MiB) block in User
     Partition 2 via `psp::mem::alloc_user_bytes(16 * 1024 * 1024, b"slim_probe\0")`
     (after the 8 MiB Rust heap arena is initialized, a 24 MiB PSP-1000 only has
     ~10-14 MiB left and will FAIL a 16 MiB allocation, whereas a 64 MiB
     PSP-2000/3000 with `MEMSIZE=1` has >35 MiB left and will SUCCEED!).
     Record whether `slim_probe` succeeded or returned an error code, then drop
     `slim_probe` so the memory is freed cleanly.
   - Initialize VRAM buffers (`get_vram_allocator().unwrap()`), `sceGuInit()`,
     `sceGuStart`, `sceGuDrawBuffer`, `sceGuDispBuffer`, `sceGuDepthBuffer`,
     `sceGuViewport`, `sceGuScissor`, `sceGuFinish`, `sceGuSync`,
     `sceDisplayWaitVblankStart`, `sceGuDisplay(true)`.
   - Initialize controller (`psp::input::enable_analog()`, `Controller::new()`).
   - Run a 60-frame loop (~1 second at 60 Hz):
     * Poll `ctrl.update()`, record `buttons`, `analog_x()`, `analog_y()`.
     * Clear screen (`sceGuClearColor`, `sceGuClear`) and draw at least one
       colored triangle/quad via `sceGumDrawArray` or `sceGuDrawArray`.
     * `sceGuFinish()`, `sceGuSync(...)`, `sceDisplayWaitVblankStart()`,
       `sceGuSwapBuffers()`.
   - Write a plain-text report to `"boot_probe.log"` via `psp::io::File::create("boot_probe.log")`
     containing:
     * `STATUS: PASS` (or `STATUS: SLIM_RAM_NOT_UNLOCKED` if 16 MiB alloc failed)
     * `INITIAL_TOTAL_FREE_BYTES: <value>`
     * `INITIAL_MAX_FREE_BYTES: <value>`
     * `RUST_VEC_64K_ADDR: <ptr>`
     * `SLIM_16MIB_ALLOC: <OK(addr) or ERR(code)>`
     * `VRAM_FBP0_OFFSET: <offset>`
     * `FRAMES_RENDERED: 60`
     * `LAST_CTRL_LX_LY_BUTTONS: <lx>,<ly>,<buttons>`
   - Call `unsafe { psp::sys::sceGuTerm(); psp::sys::sceKernelExitGame(); }`.
