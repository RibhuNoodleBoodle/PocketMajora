1. MISSION & EXACT SCOPE
----------------------------------------------------------------------
Prerequisite Gate: Step 02 MUST be `PASS`.

Your objective in Step 03:
1. Build the host-side Rust CLI tool `tools/pmm-extractor` (`std`, `x86_64-unknown-linux-gnu`)
   that implements the legal asset extraction and big-endian -> little-endian
   pack compilation pipeline defined in `docs/architecture/PSP_RUST_ARCHITECTURE.txt`:
   - Subcommand `verify-rom <path>`:
     * Reads an N64 ROM file, detects byte order from the first 4 bytes:
       - `.z64` big-endian (`0x80, 0x37, 0x12, 0x40`)
       - `.v64` byte-swapped (`0x37, 0x80, 0x40, 0x12`)
       - `.n64` little-endian word-swapped (`0x40, 0x12, 0x37, 0x80`)
     * Normalizes to big-endian `.z64` in memory.
     * Verifies internal N64 header title (`"THE LEGEND OF ZELDA"` / `"MAJORA'S MASK"`
       at offset `0x20`), game ID (`"NZSE"` at `0x3B`), and checksums:
       - 32 MiB (`0x02000000` bytes) compressed US 1.0 ROM: CRC32 `0xB428D8A7`
       - 64 MiB (`0x04000000` bytes) decompressed US 1.0 ROM: SHA-1
         `d6133ace5afaa0882cf214cf88daba39e266c078`
   - Pure-Rust `Yaz0` decompressor + `dmadata` table parser:
     * Locates `dmadata` at ROM offset `0x1A500` (1,552 entries of 16 bytes:
       `vrom_start`, `vrom_end`, `rom_start`, `rom_end`).
     * Decompresses `Yaz0`-compressed segments (`b"Yaz0"` header + uncompressed
       size + RLE/LZ sliding window) and verifies decompressed length == `vrom_end - vrom_start`.
   - XML Asset Schema Parser & Little-Endian Pack Builder (`extract --rom <path> --xml-dir majora_code/mm/assets/xml --out <pak_path>`):
     * Parses `majora_code/mm/assets/xml/**/*.xml` (1,325 XML files defining
       `<Root>`, `<File Name="..." BaseAddress="..." RangeStart="..." RangeEnd="...">`,
       `<Texture>`, `<Array>`, `<DList>`, `<Blob>`, `<Scene>`, `<Room>`, `<Collision>`,
       `<Skeleton>`, `<Limb>`, `<Animation>`, `<PlayerAnimation>`, `<TextMM>`).
     * Extracts each declared resource from the corresponding decompressed VROM
       segment, converts big-endian N64 structures (`Vtx`, `Gfx`, `Mtx`, `RGBA16`,
       `CollisionHeader`, `Scene`/`Room` commands, `TextMM` message tables) to
       16-byte aligned little-endian payloads, **pre-swizzles textures into PSP GE
       16x8 byte tiles (`PmmPakEntry::FLAG_PSP_SWIZZLED = 1`, giving 2x-4x PSP GE
       rasterization throughput for the 40 FPS / 25 ms frame budget)**, and writes
       `pmm_2s2h.pak` using `crates/pmm-schema`'s `PmmPakHeader` + sorted
       `PmmPakEntry` index table.
   - Subcommand `build-synthetic-fixture --out <pak_path>` (for ROM-less CI &
     negative testing when the user's ROM is not yet placed on disk):
     * Generates a clearly-marked non-copyrighted synthetic test pack
       (`rom_crc32 = 0x54455354` `"TEST"`) containing synthetic `OTXM` messages,
       `OVTX` vertices, `ODLT` F3DEX2 display lists, `OTEX` procedural checker/gradient
       textures, and a synthetic `OROM`/`OCOL` test room, plus corrupt-fixture
       generators for negative testing.
2. Search for the owner's legal US N64 ROM in standard untracked paths
   (`baserom.z64`, `baseroms/n64-us/baserom.z64`, `data/basrom.z64`, `data/baserom.z64`).
   - If the owner's US ROM IS present: run `pmm-extractor verify-rom` and
