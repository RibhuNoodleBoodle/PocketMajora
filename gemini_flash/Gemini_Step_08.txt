Your objective in Step 08:
1. Implement the 2S2H-derived Majora's Mask boot/title/file-select state flow in
   `crates/pmm-game` (`majora_code/mm/src/code/z_title_setup.c`,
   `majora_code/mm/src/overlays/gamestates/ovl_title/z_title.c`,
   `majora_code/mm/src/overlays/gamestates/ovl_file_choose/z_file_select.c`,
   `z_file_nameset_PAL.c`, `z_file_copy_erase.c`):
   - `TitleSetupState` (`z_title_setup.c`):
     * Initializes `gSaveContext`, loads `OTRMessage_Init()` (`sMessageTableNES`
       and `sMessageTableCredits` from `OTXM` resources in `pmm-assets`), and
       transitions to `ConsoleLogoState` (`ovl_title`).
   - `ConsoleLogoState` (`ovl_title` / `z_title.c`):
     * Renders the N64 / Majora's Mask logo fade-in, hold, and fade-out sequence
       (`coverAlpha`, `addAlpha`, `visibleDuration` timer = 200 ticks, or early
       advance on `START_BUTTON` / `A_BUTTON` press).
     * Emits F3DEX2 display list commands rendered through `pmm-gfx` and transitions
       to `FileSelectState` (`ovl_file_choose`).
   - `FileSelectState` (`ovl_file_choose` / `z_file_select.c`):
     * Initializes `SysFlashrom_InitFlash()` and reads the 3 save slots (plus
       backup and owl-save headers) from `mm-psp-save.bin`.
     * Implements the authentic `ConfigMode` state machine:
       - `CM_FADE_IN_START` -> `CM_MAIN_MENU` (Select File 1 / File 2 / File 3,
         Copy, Erase, Options)
       - `CM_NAME_ENTRY` (8-character player name entry grid + Backspace + END;
         defaults to `"Link"` if confirmed quickly)
       - Writes the newly created file via `SysFlashrom_WriteAsync` -> waits for
         the two-second confirmation timer (`40` ticks at 20 FPS) and
         `SysFlashrom_IsBusy() == 0` / `SysFlashrom_AwaitResult() == 0` before
         returning to `CM_MAIN_MENU` with the populated save slot (`ZELDA3` magic,
         3 hearts `0x30`, `"Link"`, Dawn of First Day `0x4000`, owl status).
       - `CM_COPY_SOURCE` / `CM_COPY_DEST` / `CM_ERASE_SELECT` / `CM_OPTIONS_MENU`
         (Audio: Stereo/Mono/Headset/Surround, Z-Target: Switch/Hold).
       - Selecting an existing valid save slot and pressing `A_BUTTON` / `START`
         loads the slot into `gSaveContext` and transitions `next_gamestate` to
         `OpeningState` / `DayTelopState` (`ovl_daytelop` "Dawn of the First Day -72 Hours Remain-").
2. Support both interactive PSP controller input (`PadMgr`) and a deterministic
