3. PSP TARGET CRATE DEPENDENCY POLICY (`no_std` + `alloc`)
----------------------------------------------------------------------
To keep `EBOOT.PBP` binary size small (< 3.5 MiB) and avoid `std` host-OS bloat on
`mipsel-sony-psp`:
- All PSP target crates (`pocket-majora` root binary, `crates/pmm-schema`,
  `crates/pmm-assets`, `crates/pmm-gfx`, `crates/pmm-audio`, `crates/pmm-game`) MUST be
  `#![no_std]` with `extern crate alloc;`.
- Zero heavy third-party crates on the PSP target. Hashing (CRC32, CRC64, FNV-1a),
  Yaz0 decompression, binary cursor reading, fixed-point/float math, and LRU/slab
  management are small enough (~100-300 LOC each) to write directly in `crates/pmm-schema`
  and `crates/pmm-assets` with zero external transitive dependencies.

4. HOST EXTRACTOR TOOL (`tools/pmm-extractor`) DEPENDENCY POLICY
----------------------------------------------------------------------
`tools/pmm-extractor` runs on the user's Linux/macOS/Windows host (`x86_64-unknown-linux-gnu`
here) to validate the user's legal US N64 ROM and build `data/pmm_2s2h.pak`.
- May use standard library (`std`) and minimal permissive (MIT / Apache-2.0 / Zlib) crates
  if needed (e.g., `roxmltree` (MIT/Apache-2.0) for fast zero-allocation parsing of
  `majora_code/mm/assets/xml/*.xml`, or a self-contained XML/ROM parser in Rust), pinned
  in `Cargo.lock`.
- Must NOT require network access at runtime or embed any copyrighted ROM bytes.

5. ROM PROVENANCE & COPYRIGHT SEPARATION RULES
----------------------------------------------------------------------
- Supported User ROM:
  * Game: The Legend of Zelda: Majora's Mask (US / NTSC-U 1.0)
  * Compressed 32 MiB (33,554,432 bytes) `.z64` (Big-Endian):
    - CRC32: `0xB428D8A7`
  * Decompressed 64 MiB (67,108,864 bytes) `.z64` (Big-Endian):
    - SHA-1: `d6133ace5afaa0882cf214cf88daba39e266c078` (`MM_NTSC_US_10` in
      `majora_code/docs/supportedHashes.json` and `majora_code/mm/2s2h/BenPort.h`)
  * Byte-swapped `.v64` (`0x37804012` magic) or word-swapped `.n64` (`0x40123780` magic)
    dumps of the same US 1.0 ROM will be automatically normalized to big-endian `.z64`
    (`0x80371240` magic) in memory by `tools/pmm-extractor` before checksum verification.
- Strict Git Exclusion (`.gitignore` enforced from Step 01):
  * `*.z64`, `*.n64`, `*.v64`, `*.rom`, `*.otr`, `*.o2r`, `*.pak`, `*.bin` (asset/save
    files), `*.PBP`, `*.prx`, `*.SFO`, `/target/`, `/tools/rust-psp/`, `/majora_code/`,
    `/psp_ref/` are never staged or committed.
